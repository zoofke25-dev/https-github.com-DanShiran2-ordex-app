# Ordex

Case management for growing law firms. A demo product for the AI Product Design Masterclass. All data is fake.

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:3000.

| Page | Address |
|---|---|
| Home dashboard | `/` |
| Cases | `/cases` |
| A case | `/cases/C-1063` |
| Pricing (public site) | `/pricing` |

## Figma files

Open each link and click **Duplicate** to get your own copy. Work on your copies, and give Claude Code links from them.

- [Ordex - Design system](https://www.figma.com/design/TSbLUHSQFTcv1ts1hVhw1Z/Ordex---Design-system): variables, text styles, icons and components.
- [Ordex - Designs](https://www.figma.com/design/hJMROuSBhBdlsAlFkqJJRc/Ordex---Designs): the screens, built from the design system.

## Working with Claude Code

Open Claude Code in this folder. It reads `CLAUDE.md`, which explains the stack, the Ordex tokens, and the rules. Tasks to pick up are in `STARTER-ISSUES.md`.
